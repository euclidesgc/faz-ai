# Registros de decisão

Cada história entregue pelo board deixa aqui o registro da decisão que ela tomou: o contexto, a
decisão, as alternativas descartadas (com o motivo de cada uma), as consequências e os diagramas do
desenho do programa. A Homologação grava o arquivo a partir da Spec aprovada e o leva no pull request,
com o nome `<número da história>-<título>.md`.

Quem liga é a opção **Faz AI › Git › Registros de decisão** (`fazai.git.decisionRecords`), que neste
repositório aponta para esta pasta em `.vscode/settings.json`.
