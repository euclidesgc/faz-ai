# Implementar — react-accessibility

Parta do contrato aprovado e do código existente. Inspecione consumidores antes de alterar o comportamento; para manutenção, registre o comportamento que deve ser preservado.

1. Usar primitivos acessíveis já disponíveis preservando nomes, labels e relações de descrição.
2. Implementar abertura, fechamento e retorno de foco conforme o padrão do widget; tratar remoção do acionador.
3. Anunciar resultados assíncronos pertinentes sem repetir mensagens a cada render.
4. Exercitar teclado e inspecionar árvore acessível; usar leitor de tela quando disponível e necessário ao caso.

## Verificar e entregar

Fluxo pertinente funciona por teclado, foco é previsível e semântica/mensagens são verificadas; declarar limite se não houve leitor de tela.

Execute verificações proporcionais à mudança com os comandos reais do projeto. Não acrescente teste que só repete a implementação. Informe arquivos alterados, comportamento resultante, verificações executadas e limitações concretas. Decisão transversal alterada exige atualização explícita do contrato correspondente, sem reescrever instruções por efeito implícito.
